# «Перемена» — напоминалка о звонках и задачах на перемену (Android)

Версия 0.1.0 — первая рабочая версия по ТЗ (MVP).

## Что умеет

- **Звонки по расписанию.** Вибрация за N минут до конца пары, в момент звонка
  и (по желанию) за N минут до начала пары. Работает при заблокированном экране
  и, если включено, в беззвучном режиме.
- **Задачи на перемену.** «Отнести журнал · ауд. 214 · ближайшая перемена» —
  три касания. Варианты срока: ближайшая перемена, после пары №N, точное время,
  без срока. Повтор каждый учебный день.
- **Кнопки в уведомлении:** «Выполнено» и «На след. перемену» — приложение
  открывать не нужно.
- **Режим дня одной кнопкой:** по неделе / сокращённый / без звонков (только на
  сегодня, завтра всё вернётся само).
- **Несколько шаблонов расписания** (обычный, сокращённый, суббота…) и неделя:
  какой шаблон в какой день.
- **Проверка надёжности:** приложение само показывает, если не выданы
  разрешения или включена экономия батареи, и ведёт в нужные настройки.
  Кнопка «Проверить сигнал через 1 минуту».
- **Файл расписания** (JSON по ТЗ, раздел 5.2): сохранить, загрузить,
  поделиться с коллегами.

Чего пока нет (следующие этапы ТЗ): календарь телефона, Битрикс24, Google,
синхронизация со Sticky Timer Notes.

## Первый запуск

1. Разрешите уведомления.
2. Вкладка **«Расписание»** → впишите реальное время пар (по одной паре на
   строку, `09:00-10:30`) → «Сохранить». Сейчас стоит **пример**.
3. Там же внизу «Надёжность»: всё должно быть с галочками. На Xiaomi / Honor /
   Huawei / Samsung дополнительно включите для приложения «Автозапуск» и
   «Без ограничений» в настройках батареи.
4. Нажмите «Проверить сигнал через 1 минуту», заблокируйте экран и дождитесь
   вибрации.

> Значок будильника в строке состояния — это нормально: приложение использует
> системный механизм будильников, который Android не откладывает в режиме
> энергосбережения.

## Как собрать APK

Выберите **один** способ.

### Способ A. Через GitHub, ничего не устанавливая (проще всего)

1. Создайте на GitHub новый репозиторий (можно приватный), например `peremena`.
2. Загрузите в него все файлы проекта (на странице репозитория: *Add file →
   Upload files*, перетащите содержимое папки, включая скрытую папку `.github`).
   Если папка `.github` не перетаскивается — создайте файл вручную через
   *Add file → Create new file*, имя `.github/workflows/build-apk.yml`, и
   вставьте содержимое из проекта.
3. Откройте вкладку **Actions** — сборка «Сборка APK» запустится сама
   (5–10 минут). Если не запустилась — выберите её слева и нажмите
   *Run workflow*.
4. Когда появится зелёная галочка, APK появится в разделе **Releases**
   репозитория. Постоянная ссылка на самую свежую сборку:
   `https://github.com/<владелец>/<репозиторий>/releases/latest/download/peremena.apk`
   (для этого проекта — <https://github.com/AnryKron/peremena/releases/latest/download/peremena.apk>).
   Её можно открыть прямо на телефоне. Если репозиторий приватный, в браузере
   телефона нужно быть залогиненным в GitHub.

### Способ B. На своём компьютере, `build-apk.bat`

1. Установите **Android Studio**: <https://developer.android.com/studio>
   или в консоли `winget install -e --id Google.AndroidStudio`.
2. Один раз откройте Android Studio и пройдите мастер — он скачает Android SDK.
   Убедитесь, что в *SDK Manager* установлен **Android 14 (API 34)**.
3. Распакуйте проект в папку **без кириллицы и пробелов**, например
   `C:\dev\peremena\`.
4. Дважды щёлкните **`build-apk.bat`**. Первая сборка скачивает Gradle и
   библиотеки (~500 МБ, 5–15 минут).
5. Готовый файл: `dist\peremena.apk`.

### Способ C. Из Android Studio

*File → Open* → папка проекта → дождаться синхронизации → зелёная кнопка ▶
(*Run*) с подключённым по USB телефоном (нужна «Отладка по USB» в
параметрах разработчика).

## Установка на телефон

1. Перекиньте `peremena.apk` / `app-debug.apk` на телефон (кабель, Telegram
   «Избранное», почта).
2. Откройте файл → Android попросит разрешить установку из этого источника →
   разрешите → «Установить».
3. Play Защита может предупредить о неизвестном разработчике — это из-за
   отсутствия публикации в магазине. «Всё равно установить».

Обновление: соберите новую версию и установите поверх — данные сохранятся.
Все сборки подписываются одним ключом `app/peremena.keystore`, поэтому
неважно, где собирали — на GitHub или на своём ПК. Не удаляйте этот файл:
без него новую версию придётся ставить только после удаления старой.

## Устройство проекта

```
app/src/main/java/com/andrew/peremena/
  model/Models.kt      модели данных (задача, расписание, сигналы)
  model/Plan.kt        вся логика: пары, перемены, когда сигналить (без Android)
  data/Codec.kt        JSON-формат из ТЗ, раздел 5
  data/Repo.kt         хранение (data.json, атомарная запись), действия с задачами
  alarm/AlarmScheduler планирование будильников на 36 ч вперёд
  alarm/Receivers.kt   срабатывание сигнала, кнопки уведомления, перезагрузка
  alarm/Notifier.kt    уведомления
  alarm/Signaler.kt    вибрация и звук (в т.ч. в беззвучном режиме)
  ui/                  экраны: Сегодня, Новая задача, Расписание, Надёжность
app/src/test/.../PlanTest.kt  тесты логики расписания
```

Отличие от ТЗ: вместо Room (SQLite) данные хранятся в одном JSON-файле с
атомарной записью — задач немного, а сборка проще (меньше плагинов). Формат
файла — ровно тот, что в ТЗ, раздел 5.
